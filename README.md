# grc-practice-lab
Interactive GRC compliance and control automation practice lab dashboard
A unified repository demonstrating practical implementation, automation, and evidence collection across leading global security, governance, and AI‑risk frameworks. Designed for cloud‑first environments and aligned to enterprise‑grade assurance requirements.
Purpose :
1. A consolidated control library mapped across multiple frameworks
2. Automated compliance checks using cloud-native tooling
3. Evidence generation workflows for audits
4. AI‑risk governance aligned to modern regulatory expectations

Included Frameworks
1. ISO 27001:2022 — Information Security Management System (ISMS)
2. NIST Cybersecurity Framework (CSF)
3. NIST SP 800‑53 Rev 5
4. SOC 2 Trust Services Criteria
5. COBIT 2019 — IT Governance & Management
6. NIST AI Risk Management Framework (AI RMF)

Control Mapping Strategy
This repository uses ISO 27001 Annex A as the anchor framework, then maps each control to:
1. NIST CSF functions
2. NIST SP 800‑53 control families
3. SOC 2 Trust Services Criteria
4. COBIT governance objectives
5. NIST AI RMF categories (for AI‑related systems)

Automation & Tooling
1. Azure Policy for continuous compliance
2. Defender for Cloud for security posture management
3. GitHub Actions for evidence collection and control testing
4. AI governance checks for ML pipelines
5. Sentinel for incident response automation

Security & Compliance Goals
1. Unified governance model
2. Continuous monitoring
3. Automated evidence generation
4. AI‑risk accountabilit
5. Enterprise‑grade audit readiness
